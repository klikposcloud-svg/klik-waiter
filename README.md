# Klik Waiter - Comandero Móvil

> PWA para smartphones de mesoneros con mapa de mesas y división de cuentas.

## 🚀 Inicio Rápido
```bash
# 1. Instalar dependencias
npm install

# 2. Iniciar servidor de desarrollo en puerto 3014
npm run dev
```

## 🔗 Integración con Klik POS Matrix
Este módulo se conecta a la matriz central **Klik POS** a través del protocolo unificado de eventos WebSocket/REST.
